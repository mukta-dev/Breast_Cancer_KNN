# Breast Cancer Diagnosis Prediction (KNN + K-Means)

## Objective
Classify breast cancer as:
- 1 = Malignant
- 0 = Benign

## Steps
1. Dropped id & Unnamed:32
2. Encoded diagnosis (M=1, B=0)
3. Applied Min-Max Normalization
4. Train-Test Split 80/20
5. K-Means clustering (k=2)
6. KNN classifier (k=5)
7. Evaluated: Accuracy, Precision, Recall, F1-score
